# VELO

Aplicação React + Vite para aluguel de bikes com páginas de frota, estações, usuários e aluguéis.

## Estrutura

```text
src/
  components/
    ui/                 # componentes compartilhados usados pela app
    ScrollToTop.jsx
  features/
    velo/
      assets/           # imagens da feature
      components/       # layout e componentes da feature
      data/             # JSONs e mapa de imagens
      pages/            # páginas do domínio VELO
  hooks/
  lib/
  pages/
    NotFound.jsx
```

## Scripts

```sh
npm install
npm run dev
npm run build
```
